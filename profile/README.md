## Open Source Software

As a part of our contract research, we develop and maintain open source software.
These are both developed by our group at SINTEF and in collaboration with industry,
academia and other research institutions.
Please see the respective webpages listed below for additional details.

| Software | Description |
|------|-------------|
| [![IFEM](img/opm.png)](https://github.com/OPM/IFEM) | IFEM (Isogeometric Finite Element Module) is an object-oriented toolbox for implementing isogeometric finite element solvers for linear and nonlinear partial differential equations. The purpose of this code is to serve as a common base for isogeometric PDE-simulators, using splines and NURBS as basis functions in the finite element formulations. The toolbox contains methods for doing linear and non-linear, stationary and dynamic time-domain analyses, as well as eigenvalue analyses. IFEM is parallelized using the PETSc library and enables adaptive refinement using LR B-splines based on residual or recovery methods for a posteriori error estimation. IFEM is hosted on github: [IFEM on github](https://www.github.com/OPM/IFEM), with some documentation on the [wiki pages](https://github.com/OPM/IFEM/wiki). |
| [![OpenFEDEM](img/fedem.png)](https://openfedem.org) | OpenFEDEM (Finite Element Dynamics in Elastic Mechanisms) is a comprehensive simulation package for doing dynamics simulation of flexible multi-body systems. It has been under development for more than 30 years by SINTEF, NTNU, Fedem Technology AS and SAP SE, and is now an open source project managed by our group. OpenFEDEM is hosted on the [OpenFEDEM webpages](https://openfedem.org) with the source code on [github](https://www.github.com/openfedem). |

Please visit [SINTEF Math on github](https://github.com/sintefmath) for other software projects.
